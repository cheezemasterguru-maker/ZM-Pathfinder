Lost Temple · Historical Template Recorder

Standalone administrator tool — no Pathfinder scripts or dependencies

Board setup

Select a piece, then tap its top-left placement cell. Tap a placed piece to select/remove it.

Pieces

Piece quantities are enforced. Touching is allowed; overlap is forbidden. Squares do not rotate.

Reference screenshot (optional)

The screenshot stays in your browser and is not included in exported templates.

Save / export

Saved templates live in this browser's local storage until exported. Export JSON regularly for server backups. A saved board is automatically checked against rotated/mirrored duplicates.
Template recording only. This page does not predict hidden tiles or alter the player solver. Only fully completed, inventory-valid boards can be saved.
