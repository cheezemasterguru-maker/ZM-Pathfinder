Board setup

Available pieces

Select a piece, then tap any tile it should cover. Tap a placed piece to rotate it; double-tap to remove it. Invalid placements are silently ignored.

Editing tips

Pieces are selected above the grid. The selected orientation is shown in the piece button. Tap a placed rectangular piece once to rotate it in place. Double-tap any placed piece to remove it. Touching is allowed; overlapping is not.

Reference screenshot (optional)

The screenshot stays in your browser and is not included in exported templates.

Save / export

Each verified board automatically generates all distinct valid rotations and reflections. Duplicates are checked against the existing library before saving or importing. Templates are stored locally until exported; export JSON regularly for backups.
